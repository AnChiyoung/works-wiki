# 위키 프로젝트

개발 지식을 정리하는 공개 **개발 위키**. 열람은 누구나, 편집은 운영자(관리자)가 한다. 필요하면 관리자가 회원별로 특정 기능만 승인해 줄 수 있다.

## 실행하기 (이 PC에서)

1. `npm install`
2. `.env.example`을 `.env.local`로 복사하고 필요하면 값을 바꾼다.
3. `npm run admin:create` — 관리자 계정을 만든다. (처음 한 번)
4. `npm run dev` 후 http://127.0.0.1:3000 에 접속해 상단바의 **로그인**으로 들어간다.

서버는 이 PC(127.0.0.1)에서만 접속된다. 외부 공개는 M7(Cloudflare Tunnel)에서 한다.
