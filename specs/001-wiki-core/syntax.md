# 문법 명세 (001-wiki-core)

- 상태: 확정 v1 (2026-11-17). 바꿀 때는 이 문서를 먼저 고친다.
- 결정: 마크다운(CommonMark + GFM 표) + 위키 확장 문법 (2026-11-17)
- 이 문서는 렌더러가 지켜야 할 규칙이다. 각 규칙(SX-번호)은 "입력 → 출력" 테스트로 확인한다.

## 1. 기본 원칙
- 마크다운 문법은 표준(CommonMark) 그대로 동작한다. 일반 마크다운 문서를 붙여 넣어도 깨지지 않아야 한다.
- 위키 확장은 `[[ ]]`, `{{ }}`, `:::` 세 가지 표기만 쓴다. 표기 종류를 늘리지 않는다.
- 문서 제목은 화면에 자동으로 표시되므로 본문에 따로 쓰지 않는다.
- 원시 HTML 태그는 쓸 수 없다. 글자로 그대로 보인다. (보안: [원칙 5](../constitution.md))

### 2.1 코드 블록
개발 위키라서 코드 블록을 특히 신경 쓴다.

````
```ts title="server.ts" {3,5-6}
import next from 'next'
...
```
````

| 규칙 | 입력 | 결과 |
|---|---|---|
| SX-49 | ` ```ts ` 처럼 언어를 쓴 블록 | VS Code와 같은 수준의 문법 강조. 블록 위쪽에 언어 이름이 보인다. 모르는 언어면 강조 없이 보인다 |
| SX-50 | 모든 코드 블록 | 오른쪽 위에 복사 버튼. 누르면 코드 원문(줄 번호 제외)이 복사된다 |
| SX-51 | 모든 코드 블록 | 줄 번호가 보인다. 긴 줄은 줄바꿈하지 않고 가로 스크롤 |
| SX-52 | ` ```ts title="server.ts" ` | 블록 위에 파일 이름이 보인다 |
| SX-53 | ` ```ts {3,5-6} ` | 지정한 줄이 강조 표시된다 |

- 코드 색상은 라이트/다크 모드에 맞는 테마로 자동으로 바뀐다.

## 3. 깊이에 따른 자동 양식

쓰는 사람은 깊이만 정하고, 번호와 모양은 위키가 자동으로 붙인다.

### 3.1 제목 (문단)

| 규칙 | 입력 | 결과 |
|---|---|---|
| SX-10 | `# 역사` | 1단계 제목. 자동 번호 `1.` 굵고 큰 글자, 아래 구분선 |
| SX-11 | `## 조선 시대` | 2단계 제목. 자동 번호 `1.1.` |
| SX-12 | `### 한양 천도` | 3단계 제목. 자동 번호 `1.1.1.` |
| SX-13 | `####` ~ `######` | 4~6단계. 번호 `1.1.1.1.` … 글자 크기는 단계마다 조금씩 작아진다 |

- SX-14: 번호는 문서 안 순서대로 자동 계산된다. 중간에 문단을 넣으면 뒤 번호가 알아서 바뀐다.
- SX-15: 단계를 건너뛰어도(`#` 다음 바로 `###`) 번호는 빈 단계 없이 이어진다. (예: `1.` 다음 `1.1.`)
- SX-16: 제목이 2개 이상이면 첫 제목 위에 같은 번호의 목차가 자동으로 생긴다.
- SX-17: 제목 번호를 누르면 목차로, 목차 항목을 누르면 그 제목으로 이동한다. 각 제목에는 `#s-1.1` 같은 고정 주소가 생긴다.
- SX-18: 제목을 누르면 그 문단(다음 같은 단계 제목 전까지)이 접히고, 다시 누르면 펼쳐진다. 기본은 펼침이다.

### 3.2 목록

| 규칙 | 입력 | 결과 |
|---|---|---|
| SX-19 | `- 항목` (들여쓰기 0, 2, 4칸) | 깊이별로 기호가 `●` → `○` → `■` 순서로 자동으로 바뀐다 |
| SX-20 | `1. 항목` (들여쓰기 0, 3, 6칸) | 깊이별로 `1.` → `a.` → `i.` 순서로 자동으로 바뀐다. 실제로 쓴 숫자와 상관없이 순서대로 매겨진다 |

- SX-21: 4단계 이상은 3단계 모양을 반복한다.

## 4. 위키 링크와 파일 `[[ ]]`

| 규칙 | 입력 | 결과 |
|---|---|---|
| SX-22 | `[[대한민국]]` | 문서 링크 |
| SX-23 | `[[대한민국\|우리나라]]` | "우리나라"라고 보이는 문서 링크 |
| SX-24 | `[[서울특별시#역사]]` | 그 문서의 해당 제목으로 가는 링크 |
| SX-25 | 없는 문서로 가는 링크 | 빨간색으로 보인다 |
| SX-26 | `[[분류:도시]]` | 본문에는 안 보이고, 문서 하단 분류 목록에 들어간다 |
| SX-27 | `[[:분류:도시]]` | 분류에 넣지 않고 분류 페이지로 가는 링크만 만든다 |
| SX-28 | `[[파일:서울.jpg]]` | 이미지 삽입 |
| SX-29 | `[[파일:서울.jpg\|너비=300\|설명=서울 전경]]` | 너비 지정, 설명(캡션)과 대체 텍스트 |
| SX-30 | `[[파일:없는파일.jpg]]` | 빨간 링크로 보인다 |

## 5. 각주

| 규칙 | 입력 | 결과 |
|---|---|---|
| SX-31 | `본문[^1]` + `[^1]: 내용` | 본문에 위 첨자 번호, 문서 끝에 각주 목록 |
| SX-32 | `본문[^출처]` | 이름으로 쓴 각주도 표시는 숫자로 매겨진다 |

- SX-33: 각주 번호에 마우스를 올리면(모바일은 누르면) 각주 내용이 말풍선으로 보인다.

## 6. 글자 색·크기 `{{ }}`

| 규칙 | 입력 | 결과 |
|---|---|---|
| SX-34 | `{{색:빨강\|중요}}` | "중요"가 빨간색 |
| SX-35 | `{{색:#3366ff\|글자}}` | 16진수 색 지정 (`#rgb`, `#rrggbb`만 허용) |
| SX-36 | `{{크기:+2\|큰 글자}}` | 2단계 큰 글자. `-2` ~ `+5` 단계만 허용 |
| SX-37 | `{{색:빨강\|{{크기:+1\|둘 다}}}}` | 겹쳐 쓸 수 있다 |
| SX-38 | 허용 범위를 벗어난 값 (예: `{{색:url(...)\|x}}`) | 꾸밈 없이 안쪽 글자만 보인다 |

- 이름으로 쓸 수 있는 색: `빨강, 주황, 노랑, 초록, 파랑, 남색, 보라, 회색` (영어 `red, orange, yellow, green, blue, navy, purple, gray`도 가능)
- SX-39: 이름 색은 다크 모드에서도 읽히도록 밝기가 자동 조정된다. 16진수 색은 그대로 쓴다.

## 7. 접기/펼치기 `:::`

```
::: 접기 줄거리 보기
여기 있는 내용은 처음에 접혀 있다.
**마크다운**과 [[링크]]도 그대로 쓸 수 있다.
:::
```

| 규칙 | 입력 | 결과 |
|---|---|---|
| SX-40 | `::: 접기 제목` … `:::` | "제목"만 보이고, 누르면 내용이 펼쳐진다. 기본은 접힘 |
| SX-41 | `::: 펼침 제목` … `:::` | 같은 상자지만 처음에 펼쳐진 상태 |
| SX-42 | 제목을 생략한 `::: 접기` | 제목 자리에 "펼치기"가 표시된다 |
| SX-43 | 접기 안에 접기 | 겹쳐 쓸 수 있다. 바깥 `:::`보다 콜론을 하나 더 쓴다 (`::::`) |

- SX-44: 접힌 내용도 검색 대상에 포함되고, 검색으로 들어오면 해당 부분이 자동으로 펼쳐진다.

## 9. 안전 규칙
- SX-46: `<script>`, `<iframe>` 등 모든 HTML 태그는 글자로 보인다.
- SX-47: `javascript:`, `data:` 주소의 링크는 링크가 되지 않는다.
- SX-48: 색·크기는 정해진 값만 CSS 클래스나 검증한 색 값으로 바뀐다. 사용자가 임의의 `style`을 넣을 수 없다.

## 10. 나중에 추가할 수 있는 것 (이번 범위 아님)
- 수식 (`$E=mc^2$`)
- 다이어그램 (` ```mermaid ` 블록을 그림으로)
- 동영상 삽입 (`{{유튜브:주소}}`)
- **템플릿** (사용자 요청, 나중에 추가)
  - 새 문서 양식: 새 문서를 만들 때 "인물", "장소" 같은 양식을 고르면 타이틀·부타이틀·항목·하위 항목 뼈대가 편집창에 미리 채워진다.
  - 틀 끼워넣기: `{{틀:이름|항목=값}}`으로 정보상자 같은 공통 틀을 불러온다. 틀을 고치면 그 틀을 쓴 모든 문서에 반영된다.
- 글자 배경색, 가운데 정렬
