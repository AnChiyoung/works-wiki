# 작업 목록: 위키 핵심 기능 (001-wiki-core)

- 기준: [spec.md](spec.md) · [syntax.md](syntax.md) · [plan.md](plan.md)
- 현재 단계: **M4 — 위키 링크·분류·각주·꾸밈 문법·코드 강조, 검색·최근 변경·역링크** (M1·M3 완료, M2는 T037 실사용 확인만 남음)
- 다음 단계 작업은 앞 단계 완료 점검 때 이 문서에 추가한다.

## 작업 규칙
- 작업은 번호 순서대로 진행한다. `[P]` 표시가 있는 작업은 앞 작업이 끝났다면 서로 동시에 진행해도 된다(다른 파일을 다룸).
- 각 작업의 **완료 조건**을 모두 만족해야 체크한다. 테스트가 있는 작업은 테스트를 먼저 쓰고(실패 확인) 구현한다.
- 작업 중 스펙과 다른 결정이 필요하면 코드를 고치기 전에 스펙을 먼저 고친다. ([원칙 1](../constitution.md))
- 작업 하나가 끝날 때마다 커밋한다. 커밋 메시지에 작업 번호를 넣는다. (예: `T013 문서 저장 서비스`)

## M1 범위

| 포함 | 제외 (다음 단계) |
|---|---|
| 문서 보기, 없는 문서 화면, 대문 이동 | 로그인·권한 (M2) |
| 문서 만들기·편집, 편집 요약, 미리보기 | 이력·차이·되돌리기·편집 충돌 (M3) |
| 마크다운 기본 문법, HTML 정화 | 위키 링크·분류·각주·색·접기 상자·코드 강조 (M4) |
| 제목 자동 번호·목차·문단 접기, 목록 깊이 양식 | 검색·최근 변경 (M4) |
| 리비전 저장 (덮어쓰지 않음) | 이동·파일 (M5), 관리 (M6) |

**M1 임시 규칙**: 로그인이 없으므로 서버는 이 PC(127.0.0.1)에서만 접속되게 띄우고, 환경 변수 `WIKI_OPEN_EDIT=true`일 때만 편집을 허용한다. 편집자는 내장 `system` 사용자로 기록한다. M2에서 이 규칙을 없애고 관리자 로그인으로 바꾼다. → **T035에서 제거됨.**

# M2 — 관리자 로그인과 권한

## M2 범위

| 포함 | 제외 (다음 단계) |

| 첫 관리자 생성 명령어 | 가입 신청, 회원 승인·차단 화면 (M6+) |

## 14단계: 렌더러 확장

렌더러는 순수 함수로 유지한다(plan.md §2). 문서가 있는지는 렌더러가 DB를 보지 않고, 부르는 쪽이 넘겨준 목록으로 판단한다.

- [x] **T049 위키 링크 플러그인** — AC-3.3, AC-3.10, SX-22~25, SX-27
  - `src/server/render/plugins/wikilink.ts`: `[[문서]]`, `[[문서|보이는 글]]`, `[[문서#문단]]`, `[[C\#]]`, `[[:분류:이름]]`을 링크로 바꾼다. 제목은 `parseTitle`로 정규화하고, 쓸 수 없는 제목이면 원문 글자 그대로 둔다.
  - `extractWikiData(source)`: 본문을 렌더링하지 않고 링크 대상 제목 목록과 분류 목록만 뽑는다(저장할 때 `links`·`categories` 갱신용).

  - 테스트: 한국어 부분 검색("특별시" → "서울특별시"), 2글자 검색, 제목 일치, 특수문자 검색어(`C++`, `"`, `*`가 FTS 문법 오류를 내지 않음), 최근 변경 순서·쪽 나누기, 역링크·분류 목록, 임의 문서.
  - 완료 조건: 위 테스트 통과.

## 16단계: 화면

- [ ] **T058 문서 화면에 링크·분류 반영** — AC-3.3, AC-3.4, AC-5.5
  - 문서 보기·과거 판·미리보기에서 `extractWikiData` → `existingTitles` → `renderMarkup` 순서로 빨간 링크를 표시한다.
  - 문서 하단에 "분류: 도시 · 수도" 목록(분류 페이지 링크, 분류 문서가 없으면 빨간 링크).
  - 분류 페이지(`/w/분류:이름`): 본문 아래에 "이 분류에 속한 문서" 목록(가나다순). 분류 문서가 아직 없어도 속한 문서가 있으면 목록을 보여주고 만들기 버튼을 둔다.
  - 문서 동작 버튼에 "역링크" 추가.
  - 완료 조건: 화면 테스트로 빨간 링크(누르면 편집 화면), 분류 목록, 분류 페이지 확인.

- [ ] **T059 [P] 검색 화면** — AC-5.1, AC-5.2
  - `/search?q=`: 제목이 정확히 같은 문서가 있으면 바로 그 문서로 이동한다(`?go=0`이면 이동하지 않고 결과만). 결과는 제목·발췌(일치 부분 강조)·쪽 나누기. 결과가 없으면 "'q' 문서 만들기" 링크(권한 있는 사람에게만).
  - 머리글 검색창의 "준비 중"을 없애고 실제로 동작하게 한다. 검색 결과는 `noindex`.
  - 완료 조건: 화면 테스트로 부분 검색, 제목 일치 이동, 결과 없음 확인.

- [ ] **T060 [P] 최근 변경·역링크·임의 문서** — AC-5.3, AC-5.4, AC-5.6
  - `/recent`: 위키 전체 판 목록(시각·문서·판·편집자·증감·요약, 차이 링크). 휴대폰에서는 카드 모양(T042와 같은 방식).
  - `/backlinks/:title`: 이 문서를 링크하는 문서 목록. 없으면 "이 문서를 링크하는 문서가 없습니다".
  - `/random`: 임의의 일반 문서로 이동(캐시하지 않음).
  - 머리글에 "최근 변경"과 "임의 문서" 링크(휴대폰에서는 메뉴 안).
  - 완료 조건: 화면 테스트로 세 화면 확인.
