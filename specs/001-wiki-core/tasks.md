# 작업 목록: 위키 핵심 기능 (001-wiki-core)

- 기준: [spec.md](spec.md) · [syntax.md](syntax.md) · [plan.md](plan.md)
- 현재 단계: **M1 — 프로젝트 골격, DB, 문서 열람·편집 (로그인 없이 로컬 전용)**
- M2 이후 작업은 그 단계를 시작할 때 이 문서에 추가한다.

## 작업 규칙
- 작업은 번호 순서대로 진행한다. `[P]` 표시가 있는 작업은 앞 작업이 끝났다면 서로 동시에 진행해도 된다(다른 파일을 다룸).
- 각 작업의 **완료 조건**을 모두 만족해야 체크한다. 테스트가 있는 작업은 테스트를 먼저 쓰고(실패 확인) 구현한다.
- 작업 중 스펙과 다른 결정이 필요하면 코드를 고치기 전에 스펙을 먼저 고친다. ([원칙 1](../constitution.md))
- 작업 하나가 끝날 때마다 커밋한다. 커밋 메시지에 작업 번호를 넣는다. (예: `T013 문서 저장 서비스`)

## M1 범위

| 포함 | 제외 (다음 단계) |
|---|---|
| 문서 보기, 없는 문서 화면, 대문 이동 | 로그인·권한 (M2) |
| 문서 만들기·편집, 편집 요약, 미리보기 | 이력·차이·되돌리기·편집 충돌 (M3) |
| 마크다운 기본 문법, HTML 정화 | 위키 링크·분류·각주·색·접기 상자·코드 강조 (M4) |
| 제목 자동 번호·목차·문단 접기, 목록 깊이 양식 | 검색·최근 변경 (M4) |
| 리비전 저장 (덮어쓰지 않음) | 이동·파일 (M5), 관리 (M6) |

**M1 임시 규칙**: 로그인이 없으므로 서버는 이 PC(127.0.0.1)에서만 접속되게 띄우고, 환경 변수 `WIKI_OPEN_EDIT=true`일 때만 편집을 허용한다. 편집자는 내장 `system` 사용자로 기록한다. M2에서 이 규칙을 없애고 관리자 로그인으로 바꾼다.

## 2단계: 업무 로직 (서비스)

- [x] **T011 제목 처리** — AC-1.2, AC-3.10
  - `src/server/services/title.ts`: 앞뒤 공백 제거, 연속 공백 하나로, 유니코드 NFC, 이름공간 접두어(`분류:`, `파일:`, `위키:`, `사용자:`) 분리, 금지 문자(`|`, `[`, `]`, `{`, `}`, 제어 문자)·경로 조각(`//`, `.`, `..`, 앞뒤 `/`)·길이(200자) 검사. `#`은 개발 문서 제목(C#, F#) 때문에 허용한다.
  - URL 변환: 제목 ↔ `/w/...` 경로 (공백은 그대로 인코딩, `/`는 경로 구분자로 유지).

  - 테스트: 있는 문서, 없는 문서, 특정 판 조회, 없는 판 번호.
  - 완료 조건: 위 테스트 모두 통과.

- [x] **T013 문서 저장** — AC-2.3, AC-2.4, AC-2.6

    - 문서가 없으면 만들고 1판(`kind=create`), 있으면 다음 판(`kind=edit`)을 추가

    - 최신 판과 내용이 같으면 아무것도 만들지 않고 `{ changed: false }` 반환
  - 편집 충돌 검사(`base_rev_id`)는 M3에서 추가한다. 함수 인자 자리만 미리 둔다.
  - 테스트: 새 문서, 두 번째 판, 내용 동일, 한글 바이트 수, 저장 중 오류 시 아무것도 남지 않음.
